# Barber CRM

SaaS CRM для барбершопов и салонов красоты.

## Стек

- Next.js 14
- TypeScript
- Tailwind CSS
- shadcn/ui
- Firebase
- Firestore
- Cloud Functions
- pnpm workspace
- Firebase Hosting

## Структура

- web-admin — административная панель салона
- web-widget — публичный виджет для клиентов
- functions — Cloud Functions
- shared — общие типы и утилиты
- docs — документация проекта

## Требования

- Node.js 20 LTS
- pnpm
- Firebase CLI

## Команды

pnpm install
pnpm dev:admin
pnpm dev:widget
pnpm build
