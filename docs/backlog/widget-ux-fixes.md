## 🔴 Критично

### 1. Шаги записи не в URL (браузерная кнопка Back не работает)

**Симптом:** клиент жмёт «Назад» в браузере — его **выкидывает со страницы** вместо возврата на предыдущий шаг.

**Причина:** шаг хранится в React state (`useState`), не в URL.
- `book/page.tsx:124` — `const [step, setStep] = useState<1|2|3|4>(1)`
- `book/page.tsx:577, 657, 723` — переходы через `setStep`
- `router.push` используется только для slug-редиректа (`book/page.tsx:160-162`)

**Решение:** `?step=N&mode=single|group` в query params + `router.push` при переходах + `router.back()` в кнопках «Назад».

### 2. Режим записи не в URL

**Симптом:** при перезагрузке страницы или возврате теряется выбор «Один / Несколько».

**Причина:** `bookingMode` в state.
- `book/page.tsx:139` — `const [bookingMode, setBookingMode] = useState<...>(null)`

**Решение:** `?mode=group` в URL, восстанавливать state из query при загрузке.

### 3. Внутренняя state-навигация во всех кнопках «Назад»

**Симптом:** нажатие на кнопку «Назад» в шапке группы **полностью выходит** из flow, а не возвращает на шаг назад.

**Причина:** группа использует `onExit` вместо `setStep`.
- `group-booking-flow.tsx:295-300` — кнопка «Назад» в шапке → `onExit`
- `group-booking-flow.tsx:448-453` — кнопка «← Назад» на шаге 2 → `setStep(1)`
- `group-booking-flow.tsx:519-524` — кнопка «← Назад» на шаге 3 → `setStep(2)`

**Решение:** унифицировать — все «Назад» через `router.back()` или `setStep`.

## 🟡 Средне

### 4. Имя гостя в группе блокирует переход, но не помечено

- `group-booking-flow.tsx:652-660` — поле «Имя» без `required`
- `group-booking-flow.tsx:131-139` — но `isStep1Valid` возвращает `false` при пустом имени
- Пользователь не понимает, что не так

**Решение:** либо `required` на поле, либо убрать проверку (с fallback «Гость N»).

### 5. Обязательные поля без `required`

- `group-booking-flow.tsx:663-677` — master select без `required`
- `group-booking-flow.tsx:467-478` — дата без `required`
- `book/page.tsx:678-688` — дата без `required`

**Решение:** добавить `required` или визуальную подсветку.

### 6. Двойная логика «Назад» в группе

См. пункт 3. Две кнопки с одинаковым текстом «Назад» делают **разные** вещи.

**Решение:** переименовать верхнюю кнопку → «Отменить» / «Выйти», оставить «← Назад» только для шагов.

### 7. Автовозврат на предыдущий шаг при slot_taken

- `book/page.tsx:336-338` — `setStep(3)` при ошибке
- `group-booking-flow.tsx:237-239` — `setStep(2)` при ошибке

**Проблема:** клиент теряет заполненную форму.

**Решение:** показывать ошибку **на текущем шаге**, не сбрасывать шаг.

### 8. Emoji 👤/👨‍👩‍👧 в `BookingModeSelector`

- `book/page.tsx:85-87, 99-101` — эмодзи вместо SVG

**Решение:** заменить на SVG-иконки (согласованно с остальным UI).
